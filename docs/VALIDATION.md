# Проверка LocalPrint

## Дополнение для 0.1.1

- APK 0.1.1 устанавливается поверх 0.1.0 с прежним ключом подписи; API 26 совместимость Java-кода проверена компиляцией.
- На AOSP Android 15/API 35 инструментальный `SessionProbe` открыл настоящий системный диалог и список принтеров. Ранее сохранённый SPL-принтер появился; новый PCL-принтер появился при сохранении во время открытой сессии. Переименование и удаление обновили системный список без перезапуска службы.
- При отсутствующем профиле сохранённый принтер остаётся в списке со статусом «недоступен», причина записывается в локальный журнал. Ошибка больше не проглатывается молча.
- Служба передаёт сохранённые принтеры сразу при создании сессии, а также по запросам Android и при изменениях настроек. Журнал показывает подключение Android, начало/окончание поиска и число переданных устройств; доступно копирование диагностики.
- Сообщённое отсутствие Samsung в системном списке Xiaomi/HyperOS на эмуляторе не воспроизведено. 0.1.1 добавляет диагностику для проверки на реальном телефоне; исправление именно этого случая пока не подтверждено.
- Движки и формат печатных данных в этом обновлении не менялись. Полный прогон драйверов ниже относится к 0.1.0; для 0.1.1 выполнены сборка, проверка подписи, API 26 компиляция и описанный системный сценарий.

## Проверка 0.1.0

Дата: 24 ноября 2026 года.

## Проверено

- APK собирается из Java-исходников официальными Android build-tools 36.0.0 с JDK 17; minSdk 26, targetSdk 36. Подписи APK v2 и v3 проверены `apksigner`.
- Приложение дополнительно компилируется с `android.jar` API 26 для проверки базовых Android API. Проверка включения службы использует публичный API Android 13+ через защищённую проверкой версии рефлексию; на старых версиях используется чтение настройки включённых служб.
- На одной синтетической однобитной A4-странице заголовки QPDL и распакованные полосы Java-драйвера совпали с эталонным OpenPrinting SpliX. Сравнение выполнено для SCX-3200/QPDL 3, ML-1510/QPDL 1, ML-1630/QPDL 2 и ML-1915 с отличающимися аппаратными полями.
- Независимый декодер восстанавливает случайные/повторяющиеся полосы сжатия 0x11. Выходные растры PCL 5, PostScript и PDF совпали с исходным изображением; таблица объектов PDF корректна. Проверены успешные и ошибочные статусы IPP, а также прерывание кодировщика.
- В эмуляторе AOSP Android 15/API 35 ARM64 приложение устанавливается, запускается и регистрируется как `android.printservice.PrintService`. Системный PrintManager обнаруживает службу и её возможности.
- Инструментальный тест прочитал все 53 профиля, скачал реальный PPD из закреплённой ревизии OpenPrinting с проверкой SHA-256, отклонил неподдерживаемые профили.
- Проверены реальный Android PdfRenderer, растеризация полосами, выбор одной из двух страниц, формирование PCL/PS/PDF и передача через TCP. IPP-задание принято локальным тестовым HTTP/IPP-принтером.
- Через стандартный системный диалог Android выбран принтер LocalPrint и отправлено двухстраничное задание SPL. Оно прошло `onPrintJobQueued`, было принято тестовым RAW-принтером и завершилось состоянием `STATE_COMPLETED`.
- Главный экран, каталог и форма добавления проверены на снимках эмулятора (`screenshots/qa/`). Новый принтер вводится в пустой форме; профиль выбирается из каталога. В производственном Java-коде нет пользовательского IP или отдельного маршрута для модели SCX-3200. Адрес/порт/профиль хранятся в настройках каждого принтера.
- Проверен уточнённый сценарий: автоматический DNS-SD-поиск → выбор результата → явное сохранение. В эмуляторе регистрировался тестовый принтер с произвольным именем и моделью в метаданных. До сохранения список настроенных принтеров оставался пустым; после сохранения записывался подобранный профиль. Тест подтвердил отсутствие TCP-обращений к RAW-порту и отсутствие новых заданий печати при этих действиях.
- Проверен ручной поиск по адресу → выбор доступного устройства → выбор драйвера → явное сохранение. Сетевой тестовый сервер получил пустое подключение без единого байта печатных данных; новых заданий печати не создавалось.
- Для каждого из 50 встроенных SPL-профилей создано сетевое объявление с моделью в метаданных и общим именем устройства. Общий алгоритм выбрал соответствующий профиль без списка специальных условий по моделям.

## Что ещё требует физической проверки

- Установка и включение службы на физических телефонах разных производителей, включая HyperOS и One UI.
- Реальный лист с Android через WAVLINK/SCX-3200. Прежний драйвер SpliX с Mac уже печатал на этом принтере; новая Java-реализация сравнивалась с SpliX, но это не заменяет испытание на бумаге.
- Другие 49 моделей из каталога, реальные PCL/PostScript/PDF Direct-принтеры, различные IPP/IPPS-устройства и их сертификаты.
- Работа именно на Android 8–14 и 16: заданы совместимый минимум и актуальная целевая версия; инструментальный прогон сделан на Android 15.
- Блокировки локальной сети/фоновой работы, которые могут добавлять прошивки производителей; длительные и очень большие реальные документы.

Тестовые TCP/IPP-серверы слушали loopback и не пересылали задания на пользовательский принтер. Эмулятор и отдельный тестовый APK не входят в пользовательскую сборку. В APK нет рекламных или аналитических SDK, Google Play Services, загрузки исполняемого кода или внешнего сервиса обработки документов.
