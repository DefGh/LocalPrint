# LocalPrint

Системная служба печати Android 8.0+ (minSdk 26, targetSdk 36). Документы обрабатываются на телефоне и отправляются прямо на принтер или принт-сервер. Компьютер, реклама, учётная запись и подписка не нужны.

**[Скачать тестовый APK](https://github.com/DefGh/LocalPrint/releases/latest)** · [Проверки и ограничения](docs/VALIDATION.md)

Первая версия: чёрно-белая односторонняя печать. Поддержка зависит от языка принтера; наличие устройства в каталоге не означает, что оно физически протестировано этой Android-сборкой.

## Первая настройка

1. Установить APK и открыть LocalPrint.
2. Нажать «Открыть настройки печати» и включить службу LocalPrint.
3. Нажать «Найти автоматически»: приложение ищет объявления принтеров в локальной сети через DNS-SD/mDNS и получает адрес, порт, модель и поддерживаемые форматы. Выбрать устройство из результатов. Если оно не публикует сетевое объявление, использовать «Найти вручную»: указать адрес/порт и выбрать доступное устройство.
4. Проверить или выбрать совместимый драйвер и нажать «Сохранить». До этого принтер не записывается в настройки. Поиск, выбор и сохранение не отправляют печатные задания или пробные страницы.
5. Телефон и принтер должны находиться в одной доступной друг другу сети. Сохранённый принтер затем выбирается в стандартном меню «Печать» нужного приложения.

В коде приложения нет заранее заданного пользовательского принтера, IP, отдельного маршрута по модели или персонального пресета. Профиль автоматически сопоставляется с данными устройства по общему каталогу; если метаданных недостаточно, модель выбирается пользователем.

Служба использует стандартную систему заданий Android. На Xiaomi/HyperOS и Samsung/One UI расположение раздела «Печать» может различаться; кнопка приложения открывает его напрямую.

## Драйверы и модельные профили

Встроены четыре механизма преобразования:

| Движок | Назначение | Ограничения |
| --- | --- | --- |
| SPL/QPDL | Чёрно-белые Samsung и совместимые Xerox, использующие сжатие 0x11 | QPDL 1/2/3, полосы 128, 600 dpi. JBIG/0x13/0x15 и специальные полосы не поддерживаются |
| PCL 5 Mono | Принтеры, действительно поддерживающие PCL 5 | Чёрно-белый растр, TIFF/PackBits, 300 dpi |
| PostScript Level 2 | Принтеры с интерпретатором PostScript | Чёрно-белый растр, RunLengthDecode, 300 dpi |
| PDF Direct | Принтеры, принимающие PDF напрямую по RAW или IPP/IPPS | Чёрно-белый PDF-растр, 300 dpi; наличие только IPP не гарантирует поддержку PDF |

Включены 50 монохромных модельных профилей SpliX и три универсальных профиля. Это параметры известных моделей, а не заявление о физических испытаниях всех 50 устройств. Универсального драйвера, подходящего к любому принтеру, нет. В частности, Generic PostScript не подходит к SCX-3200.

Источник загрузок — официальный репозиторий [OpenPrinting/SpliX](https://github.com/OpenPrinting/splix). Каталог привязан к конкретной ревизии; приложение проверяет SHA-256 каждого скачанного PPD. Также можно импортировать совместимый PPD или JSON из файла. PPD используется только как данные: `cupsFilter`, shell-команды и PostScript-фрагменты профиля не исполняются.

Скачивание профиля меняет настройки модели в уже встроенном движке. Новый язык принтера требует нового движка и обновления APK. Драйверы Windows (`.exe`, `.dll`), произвольные Linux-фильтры и загружаемые библиотеки не поддерживаются. Каталог обновляется при выпуске приложения; его можно пересобрать из новой проверенной ревизии SpliX командой `python3 tools/generate_catalog.py`.

## Что поддерживает первая версия

- Добавление нескольких принтеров по IPv4/имени узла; адрес и порт задаются отдельно.
- Автоматический поиск объявлений RAW, IPP и IPPS через DNS-SD, последовательное разрешение найденных устройств и подбор профиля по метаданным. Если принт-сервер не публикует объявление, требуется ручной поиск по адресу. Массовое сканирование портов подсети и SNMP пока не реализованы.
- RAW/JetDirect; IPP/IPPS Print-Job для PDF Direct. Для IPPS используется обычная проверка TLS без обхода ошибок сертификата.
- A4, A5, Letter и Legal; выбранные страницы, копии и отмена задания.
- Монохромная односторонняя печать; ландшафтная страница поворачивается в физическую портретную подачу.
- Обработка PDF полосами с ограниченной памятью. Исходный PDF до 100 МБ, не более 200 исходных страниц, до 99 копий/500 выходных страниц и 256 МБ подготовленного потока.
- Один последовательный исполнитель заданий, очистка временных файлов после задания, локальный статус последнего задания.

Пока нет цветной печати, аппаратного дуплекса, USB/Bluetooth, SNMP-статуса, аутентификации IPP, PCL XL, ESC/P-R, CAPT и других фирменных host-based протоколов. При RAW статус «отправлено» означает успешную передачу байтов; принтер не подтверждает приложению физический выход листа. Отмена может остановить передачу, но не отзывает уже полученные принтером страницы. Ориентацию, поля и качество нужно проверить на настоящем устройстве.

## Сборка

Сборка без Gradle и сторонних runtime-зависимостей. Нужны macOS и JDK 17. Пакеты Android SDK загружаются из официального репозитория Google в локальную `.toolchain`; контрольные суммы сверяются с репозиторием.

```sh
python3 tools/bootstrap.py
./build.sh
```

Если JDK находится в другом месте, задать `LOCALPRINT_JDK`. Результат: `build/LocalPrint-0.1.0.apk`. Локальный ключ разработки хранится в `.signing/localprint-dev.jks` и не входит в архив исходников; он нужен для установки совместимых обновлений этой сборки. Для публичного релиза следует использовать собственный ключ выпуска и отдельный процесс публикации.

Исходники SpliX и ревизия находятся в `third_party/splix`. Генерированные профили уже включены; обычная сборка не обращается к GitHub. Каталог можно воспроизвести командой `python3 tools/generate_catalog.py`.

## Проверки

`bash test.sh` проверяет алгоритмы на JVM и собирает эталонный SpliX из включённых исходников. Нужны компилятор Xcode Command Line Tools и системная библиотека CUPS macOS. Для одной и той же синтетической страницы сравниваются заголовки QPDL и декодированные полосы; дополнительно проверяются произвольные данные, PCL/PS/PDF, PDF-таблица объектов, обработка ответов IPP и отмена.

`tests/AndroidProbe.java` — отдельный инструментальный тест для одноразового эмулятора Android. Он проверяет реальные PdfRenderer, профили/загрузки, сетевые транспорты и завершение задания через PrintService. Его APK не является частью пользовательского приложения. Тестовые RAW/IPP-серверы слушают только loopback и ничего не пересылают на настоящее оборудование.

Проверки и ограничения конкретной сборки записаны в `docs/VALIDATION.md`.
